# 2026-07-28 工作记录

## profile 详情「无数据 + 无曲线」修复（log 5）

用户附 `gagmate_combined(5).log`，反馈 profile 详情仍空白（联网时仪表盘当前曲线已能缓动）。

### 根因
- 详情页取数：`fetchedPhases`(联网实时) → 回退本地 `phasesJson`。打开详情时机器刚好断连（`GET /api/profile/{id}`、`api/shots/latest` 全 `Failed to connect`），实时三路全失败 → 空；本地 `phasesJson` 仍是 `"[]"`。
- `phasesJson` 为空的根因：旧 `syncProfiles` 只初始化 `"[]"`，把填充寄托于 WS `d_prof` 收集器，但该路径不稳（依赖同步时 WS 连接 + name 匹配），多数 profile 从未被写入真实相位。即使写入，curve 也恒 FLAT。

### 修复（已 `assembleDebug` 绿，未提交）
- `SyncManager.syncProfiles`：对每条 `SYNCED` profile，当连接可用且尚未含真实 curve 时，调 `getProfileDetail(mId)` 把真实 `EASE_*` 相位写回 `phasesJson`（best-effort，不覆盖本地已编辑）。→ 离线也能从本地库读带缓动曲线。
- `ProfileRepository` WS→Room 收集器：写 `d_prof` 时沿用 `phasesJson` 已有真实 curve（同序相位），避免后续 FLAT WS 覆盖缓动。
- `ProfileDetailScreen.chartPhases`：实时取到真实 curve 用实时值；否则优先本地 `phasesList`（现含真实 curve）；最后回退 FLAT 实时值。
